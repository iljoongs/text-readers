# mvp-spec.md

Phase 1(MVP)에서 즉시 개발 착수할 기능의 상세 명세. 여기 명시된 범위만 우선 구현하고, 그 외 기능은 `roadmap.md`의 Phase 2~4로 미룬다.

## 1. 파일 불러오기

- 지원 형식: `.txt`만 (`.md`는 Phase 4에서 지원 검토)
- Windows 표준 파일 열기 다이얼로그(`Microsoft.Win32.OpenFileDialog`) 사용
- 파일 열기 실패(권한, 손상 등) 시 사용자에게 오류 메시지 표시

## 2. 인코딩 자동 감지

- `UTF.Unknown` NuGet 패키지 사용 (`architecture.md` 참고)
- 감지 대상: UTF-8, EUC-KR을 최우선으로 커버
- 감지 실패 시 UTF-8로 fallback

## 3. 페이지 넘김 (페이지형)

- 스크롤이 아닌 "페이지 단위" 전환
- Phase 1에서는 애니메이션 없이 즉시 전환
- 입력 방식:
  - 키보드: 좌/우 방향키, `Page Up`/`Page Down`
  - 마우스: 좌우 클릭 영역 또는 하단 버튼
- 페이지 분할은 현재 창 크기 + 폰트 크기 + 여백 설정에 따라 동적으로 재계산

## 4. 폰트 / 여백 조절 (통상적 범위)

- **폰트 크기**: 조절 슬라이더 또는 +/- 버튼 (예: 12pt~32pt 범위)
- **줄간격**: 조절 가능 (예: 1.0~2.0배)
- **좌우/상하 여백**: 조절 가능 (프리셋 3단계: 좁게/보통/넓게 정도로 시작)
- **폰트 종류 선택**: 아래 5종 중 선택 가능

### 임베딩 한글 폰트 5종

| 폰트명                              | 계열       | 용도        |
| -------------------------------- | -------- | --------- |
| Noto Serif KR                    | 명조(세리프)  | 본문 기본값    |
| Nanum Myeongjo (나눔명조)            | 명조(세리프)  | 본문 대안     |
| RIDIBatang (리디바탕)                | 명조(세리프)  | 본문 대안     |
| Nanum Barun Gothic (나눔바른고딕)      | 고딕(산세리프) | 가독성 중시 옵션 |
| Spoqa Han Sans Neo (스포카 한 산스 네오) | 고딕(산세리프) | 가독성 중시 옵션 |

- 모두 무료/상업적 이용 가능 라이선스(OFL 등) 폰트
- `.ttf`/`.otf` 파일을 `Assets/Fonts/`에 포함하여 앱에 임베딩 (시스템 미설치 환경에서도 동작해야 함)
- 기본값은 Noto Serif KR

## 5. 마지막 읽은 위치 저장/복원

- 파일별로 마지막 페이지(또는 문자 오프셋) 저장
- 저장 위치: `./data/library.json`
- 앱 재실행 시 마지막으로 열었던 파일과 위치를 자동 복원 (또는 최소한 파일 목록에서 이어보기 가능하도록)

## 6. 창 크기/위치 저장/복원

- 창을 닫을 때(`Window.Closing`) 위치(`Left`/`Top`), 크기(`Width`/`Height`), 최대화 여부를 저장
- 저장 위치: `data/settings.json`의 `Window` 필드
- 다음 실행 시 저장된 위치/크기로 창을 띄움. 저장된 값이 없거나(최초 실행) 비정상적으로 작으면(가로/세로 200px 미만) 기본 크기로 시작

## 7. 데이터 저장 형식

- JSON, `System.Text.Json` 사용
- 저장 파일:
  - `data/settings.json`: 폰트, 크기, 여백, 테마 등 앱 전역 설정 + 창 크기/위치
  - `data/library.json`: 열었던 파일 경로, 각 파일의 마지막 읽은 위치
- 저장 시점: 설정 변경 즉시 + 앱 종료 시 + 페이지 이동 시(디바운스 처리 권장)

## MVP 완료 기준 (Definition of Done)

- [x] .txt 파일을 열어 인코딩이 깨지지 않고 표시된다
- [x] 페이지 단위로 좌우 이동이 가능하다
- [x] 폰트 크기/줄간격/여백/폰트 종류를 바꿀 수 있고 즉시 반영된다
- [x] 앱을 껐다 켜도 마지막 읽은 위치로 돌아온다
- [x] 앱을 껐다 켜도 창 크기/위치가 그대로 유지된다
- [x] 5종 한글 폰트가 모두 정상 렌더링된다 (시스템에 폰트 미설치 상태에서도)
